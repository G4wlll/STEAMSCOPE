# SteamScope

**إطار عمل OSINT لـ Steam بواجهة كونسول على طريقة Metasploit**

استخبارات من البيانات العامة فقط: تحليل الهوية، إحصائيات اللعب، رسم شبكة الأصدقاء، والبحث خارج Steam (نتائج Google، منصات أخرى، مواقع الإحصائيات، أرشيف الإنترنت).

المطوّر: **G4wlll** · [English](README.md)

## ما هي الأداة؟

SteamScope أداة بايثون بملف واحد تجمع المعلومات **العامة** عن حساب Steam وتحللها وتعرضها بتقرير واضح. ما تتجاوز أي إعدادات خصوصية: أي شيء خاص عند صاحب الحساب تتخطاه وتبلغك أنه خاص.

### المميزات
- **تحويل المعرّفات:** SteamID64 وSteam2 وSteam3 والاسم المخصص (vanity) وروابط البروفايل.
- **البروفايل:** الاسم، الدولة، المستوى، الشارات، الحظر (VAC وألعاب ومجتمع واقتصاد)، وعمر الحساب (دقيق إذا عام، وتقدير إذا مخفي).
- **الألعاب:** عدد الألعاب، مجموع الساعات، نسبة غير الملعوب، التوزيع، أكثر الألعاب لعباً، وتقدير سعر المكتبة (اختياري).
- **سجل الأسماء** القديمة.
- **شبكة الأصدقاء:** رسم العلاقات بين الأصدقاء، مؤشرات المركزية (betweenness وcloseness وPageRank)، اكتشاف المجتمعات، المجموعات المشتركة.
- **الإنفنتوري العام** مع تقدير قيمة (حد أدنى).
- **البحث على Google:** استعلامات ذكية (الـ ID بكل صيغه، روابط البروفايل، الأسماء على مواقع التواصل والتطوير والألعاب) وكل نتيجة تاخذ **درجة ثقة** مع الدليل.
- **فحص نفس الاسم على منصات أخرى** (GitHub وReddit وKeybase وGitLab وغيرها) بحكم لكل نتيجة: `corroborated` أو `plausible` أو `unverified` أو `conflict`.
- **OpenDota وFACEIT** بالربط المباشر مع الـ ID، **وInternet Archive**، **ودعوات Discord**.
- **كونسول تفاعلي** (`use` و`set` و`run` وTAB للإكمال) مع ملاحظات وثيمات.
- **تصدير** JSON وتقرير HTML وملفات CSV.

## تحذيرات مهمة

- **للاستخدام المصرّح به فقط:** البحث الأمني والأكاديمي والصحافة وفحص حساباتك أنت، أو أي حالة عندك فيها سبب قانوني وصلاحية.
- **ممنوع استخدامها للمضايقة أو التتبع أو الابتزاز أو كشف بيانات الناس (doxxing) أو التشهير.** حتى المعلومات العامة تسبب أذى حقيقياً وقد تكون مخالفة للقانون بدولتك.
- **تطابق الاسم لا يثبت أن الشخص هو نفسه.** الأسماء الشائعة يشترك بها آلاف. أي نتيجة أقل من `high` أو `corroborated` هي مجرد خيط للتحقق، وليست استنتاجاً. لا تنشر اتهامات بناءً على نتائج الأداة.
- **احترم الخصوصية:** الأداة ما تتجاوزها، وأنت ما تحاول تتجاوزها بطرق ثانية.
- **التزم بالشروط والقوانين:** [شروط Steam Web API](https://steamcommunity.com/dev/apiterms)، وشروط كل خدمة تتصل بها الأداة، وقوانين حماية البيانات في بلدك.
- **التقارير فيها بيانات شخصية:** خزّنها بأمان، شاركها فقط مع من يحتاجها، واحذفها عند الانتهاء.
- **لا ترفع مفاتيحك على GitHub.** المفاتيح تنحفظ بـ `~/.steamscope.json` وملف `.gitignore` المرفق يستثني التقارير والإعدادات.
- **بدون ضمان:** الأداة تُقدَّم كما هي، والمطوّر غير مسؤول عن سوء الاستخدام أو دقة بيانات الأطراف الثالثة.

## التنزيل

**بـ Git:**
```bash
git clone https://github.com/YOUR_USERNAME/SteamScope.git
cd SteamScope
```
**أو ZIP:** من صفحة المشروع اضغط **Code ← Download ZIP**، فك الضغط، وافتح الطرفية داخل المجلد.

## التثبيت

يحتاج **Python 3.10+** (3.9 غالباً يشتغل):
```bash
pip install -r requirements.txt
```
على Windows إذا ما اشتغل `python` استخدم `py`. الأفضل **Windows Terminal** لعرض الشعار.

فحص سريع بدون إنترنت:
```bash
python steamscope.py selftest
```

## المفاتيح (كلها اختيارية)

| المفتاح | لأي شي | من وين |
|---|---|---|
| Steam Web API | الأصدقاء والألعاب والحظر والمستوى | <https://steamcommunity.com/dev/apikey> (مجاني، وحسابك لازم يكون غير محدود) |
| مفتاح البحث | نتائج Google | [Serper.dev](https://serper.dev) أو [SerpAPI](https://serpapi.com) أو [Brave](https://brave.com/search/api/) |
| FACEIT | ربط الـ ID بحساب FACEIT | <https://developers.faceit.com> |

> **ملاحظة عن Google:** الـ API الرسمي القديم (Custom Search) مقفول للمشتركين الجدد ويتوقف بتاريخ 1 يناير 2027، والسحب المباشر من google.com يخالف شروطهم. لذلك الأداة تجيب نتائج Google عبر خدمات مرخصة. بدون مفتاح بحث تولّد لك الأداة روابط جاهزة تفتحها بالمتصفح.

داخل الكونسول:
```
set API_KEY مفتاح_ستيم
set SEARCH_PROVIDER serper
set SEARCH_KEY مفتاح_البحث
save
```

## التشغيل

```bash
python steamscope.py
```
```
steamscope > check
steamscope > use footprint
steamscope (recon/footprint) > set TARGET gabelogannewell
steamscope (recon/footprint) > run
steamscope (recon/footprint) > export reports
```

**الأهداف المقبولة:** SteamID64، رابط البروفايل، الاسم المخصص، `STEAM_0:1:123`، `"[U:1:123]"` (بين علامتي تنصيص).
اسم العرض الظاهر على البروفايل **ما يصلح** كهدف لأن Steam ما يوفر بحث به وهو يتكرر.

اكتب `help` لقائمة الأوامر كاملة، و`help <أمر>` للتفاصيل.

### الموديولات
| الموديول | وظيفته |
|---|---|
| `recon/full` | كل شيء |
| `recon/network` | شبكة الأصدقاء |
| `recon/footprint` | البحث خارج Steam فقط |
| `recon/inventory` | البروفايل والإنفنتوري |
| `recon/resolve` | تحويل المعرّفات |
| `recon/compare` | مقارنة حسابين |

### بدون كونسول
```bash
python steamscope.py scan gabelogannewell --out reports
python steamscope.py compare vanityA vanityB
python steamscope.py --help
```

## كيف تقرأ النتائج
- **نتائج الويب:** تطابق الـ ID أو الرابط الكامل = قوي. الاسم القصير أو الشائع = ضعيف. الدرجات: `high` وmedium وlow.
- **أحكام الحسابات:** `corroborated` (الحساب يشير لنفس بروفايل Steam بالضبط)، `plausible`، `unverified` (نفس الاسم فقط، ليس دليلاً)، `conflict` (يشير لبروفايل Steam مختلف، غالباً شخص ثاني).
- **عمر الحساب** تقديري (±1-2 سنة) إذا كان الإنشاء مخفياً، وقيمة الإنفنتوري حد أدنى.

## قيود
- شبكة الأصدقاء مبنية على **عيّنة** من قوائم الأصدقاء، فالمؤشرات تقريبية.
- Steam والمواقع الثانية تغيّر الواجهات بدون إشعار، وقد يتعطل جزء ويتحول لتحذير.
- الأداة اختُبرت باختبارات وحدة واستجابات تجريبية. إذا طلع خطأ بالاستخدام الحقيقي افتح Issue مع نص الخطأ كاملاً.

## الشفافية
الأداة **ملف بايثون واحد مقروء**، بدون تعتيم للكود ولا تتبّع ولا تحديث تلقائي ولا تحميل كود من الإنترنت. مفاتيحك ترسل فقط للخدمة التي تخصها. تقدر تتحقق بنفسك:
```bash
grep -nE "\beval\(|\bexec\(|subprocess|os\.system|base64|pickle|__import__" steamscope.py
grep -oE "https?://[a-zA-Z0-9._-]+" steamscope.py | sort -u
```
المطابقة الوحيدة المتوقعة في الأمر الأول هي أمر `clear`.
